# AI-Based IT Specialization and Course Recommendation System

A knowledge-based recommendation system developed for IT3182 – Essentials of Artificial Intelligence.

## AI Techniques
- Weighted academic scoring
- Interest-based matching
- Rule-based course eligibility

The system uses predefined weights and rules; no trained machine-learning model or neural network is used.

## Run the Application

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Run Tests

```bash
pytest -q
```
